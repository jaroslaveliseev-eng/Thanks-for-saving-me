# Tanks 3D

Клиентская часть браузерной 3D-танковой игры на **Three.js**.  
Ангар с выбором танка, 3D-модели, ветки наций, улучшения и интерфейс боя.

> **Важно:** серверная часть (`api.php` и логика на бэкенде) в этот репозиторий **не входит**.

---

## Структура репозитория

```
├── index.html          # UI, стили, точка входа
├── game.js             # Клиент: Three.js, ангар, бой, сеть
├── gen_models.py       # Генератор GLB-моделей танков
├── models/             # 24 готовых .glb (нация × класс)
│   ├── ussr_light.glb
│   ├── ussr_medium.glb
│   ├── ussr_heavy.glb
│   ├── ussr_wheeled.glb
│   ├── usa_*.glb
│   ├── britain_*.glb
│   ├── china_*.glb
│   ├── europe_*.glb
│   ├── germany_*.glb
│   └── manifest.json
└── README.md
```

## Возможности клиента

| Функция | Описание |
|---------|----------|
| **Ангар** | Выбор танка, 3D-превью, информация, улучшения |
| **Бой** | Рендер на Three.js (логика боя — на сервере) |
| **Ветки наций** | СССР, США, Великобритания, Китай, Европа, Германия |
| **Классы танков** | Лёгкий, средний, тяжёлый, колёсный |

| **Чат и лидерборд** | Интерфейс (данные приходят с сервера) |
| **Мобильная версия** | Адаптированный UI и touch-управление |

## 3D-модели танков

Модели лежат в `models/` в формате **glTF 2.0 Binary (.glb)**.

### Иерархия узлов (обязательная)

```
hull
 └── (колёса / гусеницы)
turret          ← пивот башни
 └── gun        ← ствол
      └── muzzle ← точка вылета снаряда (+Z вперёд)
```

- Оси: **+Y** вверх, **+Z** вперёд (дуло).
- Материал `"paint"` перекрашивается игрой под цвет танка / команды.
- Материалы `"dark"`, `"metal"`, `"track"` — фиксированные.

### Порядок поиска модели

1. `models/<id_танка>.glb`
2. `models/<нация>_<класс>.glb` (например `ussr_medium.glb`)
3. `models/<класс>.glb`
4. Если ничего нет — процедурная модель из `game.js`

### Генерация своих моделей

Нужен Python 3.8+ и `numpy`:

```bash
python3 gen_models.py models
```

Скрипт создаёт 24 файла (6 наций × 4 класса) и обновляет `manifest.json`.  
Параметры геометрии задаются в словарях `CLS` и `NAT` внутри `gen_models.py`.

## Запуск клиента

1. Положите `index.html`, `game.js` и папку `models/` на любой веб-сервер (или откройте через Live Server).
2. Клиент ожидает работающий бэкенд по адресу `api.php` (не входит в этот репозиторий).
3. Без сервера доступны только визуальная часть ангара и 3D-модели.

## Требования

| Компонент | Минимум |
|-----------|---------|
| Браузер   | Современный с WebGL (Chrome, Firefox, Safari, Edge) |

## Примечания

- Серверная часть намеренно отсутствует в репозитории.
- Логика боя, авторизация, сохранение прогресса и чат работают только при наличии бэкенда.
- Модели можно свободно править и пересобирать через `gen_models.py`.
